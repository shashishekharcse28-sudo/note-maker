SECTION 1: HOW IT WORKS (User Flow)
================================================================================

  PAGE 1: "/" — PASTE & GENERATE (Landing Page)
  ──────────────────────────────────────────────
  Beautiful dark full-screen page with:
    - StudyOS logo + tagline
    - Large textarea to paste ChatGPT/Gemini content
    - Style selector (Colorful / Clean / Academic / Dark)
    - Big "✨ Generate Notes" button
    - "Or go to Notebook →" link (skip AI, write manually)
    - "Or go to Canvas →" link (skip notes, draw directly)

  On success → stores HTML in localStorage → redirects to /notebook

  PAGE 2: "/notebook" — FULL-SCREEN NOTES
  ────────────────────────────────────────
  Full-width TipTap rich text editor showing AI-generated notes.
  NavBar on top with:
    - "✨ New from AI" button → goes back to "/"
    - "🎨 Canvas" button → goes to "/canvas"
    - Document title, autosave indicator
  Notes are FULL WIDTH — no cramped split. Beautiful and readable.
  User can edit everything. Auto-saves to localStorage.

  PAGE 3: "/canvas" — FULL-SCREEN CANVAS (already exists!)
  ────────────────────────────────────────────────────────
  This is what we already have today. Full-screen Excalidraw.
  NavBar on top with:
    - "📝 Notes" button → goes to "/notebook"
    - "✨ New from AI" button → goes to "/"
  User draws freely. Canvas auto-saves (already working).

  FLOW DIAGRAM:

  └─────────────┘    └──────────────┘    └──────────────┘
        ↑                   │                    │

              "✨ New from AI" button on both pages

SECTION 4: BUILD STEPS
================================================================================

  STEP 1: Install Dependencies
  ────────────────────────────
  npm install openai @tiptap/extension-highlight @tiptap/extension-table
              @tiptap/extension-table-row @tiptap/extension-table-cell
              @tiptap/extension-table-header @tiptap/extension-underline
              @tiptap/extension-image @tiptap/extension-link
              @tiptap/extension-color @tiptap/extension-text-style

  STEP 2: API Key — DONE ✅
  ─────────────────────────
  Using AiCredits (aicredits.in) third-party provider.
  Key and baseURL already configured in .env.local and route.ts.

  STEP 3: Build Page 1 — Paste & Generate Landing ("/")
  ─────────────────────────────────────────────────────
  Convert PasteModal into a full-page component (PastePage.tsx).
  On success: localStorage.setItem("studyos-pending-notes", html)
  Then: router.push("/notebook")

  STEP 4: Build Page 2 — Full-Screen Notes ("/notebook")
  ──────────────────────────────────────────────────────
  New route: src/app/notebook/page.tsx
  Full-width TipTap editor. On mount, checks localStorage for
  "studyos-pending-notes" → injects into editor → deletes key.
  NavBar has "Canvas" and "New from AI" navigation buttons.

  STEP 5: Move Canvas to Page 3 ("/canvas")
  ──────────────────────────────────────────
  Move current page.tsx content to src/app/canvas/page.tsx.
  NavBar has "Notes" and "New from AI" navigation buttons.

  STEP 6: Enhance TipTapEditor
  ─────────────────────────────
  Add extensions for tables, highlights, images, links.
  Accept initialHtml prop. Auto-save to localStorage every 2s.

  STEP 7: Add Callout CSS to globals.css
  ───────────────────────────────────────
  Styles for .callout, .callout-definition, .callout-example,
  .callout-important, .callout-tip, .formula-box, mark, table, etc.

  STEP 8: Update NavBar
  ─────────────────────
  Context-aware: shows different buttons based on current page.
  Page 1: Minimal (logo only)
  Page 2: "✨ New from AI" + "🎨 Canvas" + doc title + autosave
  Page 3: "✨ New from AI" + "📝 Notes" + doc title + autosave

  STEP 9: Auto-Save System
  ─────────────────────────
  localStorage keys:
    "studyos-pending-notes" → Temporary (Page 1 writes, Page 2 consumes)
    "studyos-notes"         → Persistent (Page 2 auto-save)
    "studyos-excalidraw"    → Persistent (Page 3, already exists)
