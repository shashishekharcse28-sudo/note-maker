FEATURE 3: DOCUMENT TITLE (Auto-save)
--------------------------------------------------------------------------------
Status      : ⚠️ Partial
Smoothness  : 6/10
Bugs Found  :
  - Editing the title field and pressing Enter correctly shows "Autosaved"
    and writes to localStorage key "studyos-doc-title".
  - BUG: On page reload, the title resets to "Untitled Document" instead
    of restoring from localStorage.
  - Root cause: The NavBar title input initializes its defaultValue from
    a hardcoded string, not from localStorage.
Engineer Suggestion:
  - In NavBar.tsx, initialize the title state with:
      useState(() => localStorage.getItem('studyos-doc-title') || 'Untitled Document')
  - Wrap in typeof window check for SSR safety.
  - Also consider debounced auto-save on every keystroke (not just Enter).
Priority    : P2

FEATURE 4: DRAWING — FOUNTAIN PEN
--------------------------------------------------------------------------------
Status      : ✅ Working
Smoothness  : 8/10
Bugs Found  :
  - Stroke rendering is smooth and immediate on pointer-down.
  - Catmull-Rom pressure curve is active and produces natural tapers.
  - Minor: the pen settings sliders (Tip Sharp, Pressure, Stabilize) are
    present but their effect on the stroke feel is very subtle at mid-range
    values. The difference between Stabilize=6 and Stabilize=80 is barely
    perceptible.
Engineer Suggestion:
  - The stabilization slider should use a proper Laplacian smoothing pass
    over the raw input points — collect the last N points into a ring buffer
    and emit the running weighted average as the smoothed position.
    Currently it seems to only affect Excalidraw's native smoothing param.
Priority    : P3

FEATURE 7: HIGHLIGHTER TOOL — CORE RENDERING
--------------------------------------------------------------------------------
Status      : ✅ Working
Smoothness  : 8/10
Bugs Found  :
  - The highlight renders as a wide, semi-transparent stroke with the correct
    multiply blend mode — text underneath remains readable.
  - No faint middle line visible in latest build (opacity 0 + transparent
    strokeColor fix is working correctly).
  - Slight 300ms delay between lifting the pen and the native stroke
    being hidden (replaced by our custom overlay). This is a known
    architectural limitation of the deferred suppression approach.
Engineer Suggestion:
  - Reduce the suppression delay from 300ms to 150ms. Excalidraw typically
    finalizes the freedraw element within ~2-3 animation frames of pointerup.
  - Alternatively, listen to the Excalidraw `onPointerUp` prop callback
    (not window pointerup) for more precise timing.
Priority    : P2

FEATURE 14: ERASER
--------------------------------------------------------------------------------
Status      : ✅ Working
Smoothness  : 7/10
Bugs Found  :
  - The native Excalidraw stroke eraser works — dragging over elements
    deletes them.
  - NOTE: The custom EraserEngine.ts was previously removed (commit 7b82991)
    due to performance lag. The fallback to native eraser is functional but
    less precise — it erases entire elements, not partial strokes.
  - Highlighter strokes can be erased, but since they are invisible native
    elements, the user must click precisely in the area where the invisible
    stroke geometry is, which is non-intuitive.
Engineer Suggestion:
  - IMPORTANT: When the eraser passes over the highlighter overlay canvas,
    it should erase the visible overlay pixels. This requires custom hit-
    testing: on eraser pointerdown/move, check if any highlighterSetRef
    element's bounding box is hit, remove it from the ref, and call
    drawHighlighter() to repaint without that element.
Priority    : P1 — The highlighter is not properly erasable right now.

FEATURE 15: UNDO / REDO
--------------------------------------------------------------------------------
Status      : ✅ Working
Smoothness  : 9/10
Bugs Found  :
  - Ctrl+Z and Ctrl+Y work as expected via Excalidraw's built-in history.
  - Undo/Redo buttons in the bottom-left toolbar also work.
  - CAVEAT: Undoing a highlighter stroke removes the native Excalidraw
    element but does NOT immediately redraw the custom overlay canvas.
    The overlay cleans up on the next onChange event (within ~100ms), so
    there is a very brief visual ghost of the highlight before it disappears.
Engineer Suggestion:
  - In the onChange handler, immediately clean up deleted elements from
    highlighterSetRef and call drawHighlighter() — this is already partially
    implemented in the cleanup loop. Verify it fires fast enough.
Priority    : P2
