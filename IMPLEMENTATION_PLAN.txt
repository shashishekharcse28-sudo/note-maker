THE PRODUCT IN ONE SENTENCE
================================================================================

  StudyOS: Paste any AI-generated content → get stunning, professional
  study notes with diagrams and figures → edit them in your notebook
  alongside a freehand drawing canvas.

================================================================================
HOW IT WORKS (User's Perspective)
================================================================================

  STEP 1: User clicks "✨ New from AI" button in the NavBar
          → A beautiful full-screen modal opens

  STEP 2: User pastes their ChatGPT/Gemini/Claude response into the modal
          → Raw text appears in a textarea

  STEP 3: User clicks "Generate Notes ✨"
          → Loading animation plays (2-5 seconds)
          → Behind the scenes:
             a) We send the raw text to the AI API
             b) AI returns structured, beautified HTML with:
                - Proper headings, subheadings
                - Definition boxes, example cards, key highlights
                - Mermaid diagram code for any processes/cycles
                - Image descriptions (which we then generate)
             c) We render the HTML into the TipTap editor
             d) Mermaid diagrams auto-render as SVG
             e) AI-generated images load in (if applicable)

  STEP 4: Beautiful notes appear in the notebook panel
          → User can edit anything — text, headings, reorder blocks
          → User can draw on the canvas beside the notes
          → Everything auto-saves

  THAT'S IT. Paste → Click → Beautiful notes. Done.

PHASE 2: THE AI ENGINE (Backend)
Estimated time: 1 session (~2-3 hours)

  What we build:
    [2.1] Next.js API Route: /api/generate-notes
          - Receives: raw text + style preference
          - Sends to AI API with a carefully crafted system prompt
          - The system prompt tells the AI to:
            • Structure the content with H1, H2, H3 headings
            • Wrap definitions in <div class="callout-definition">
            • Wrap examples in <div class="callout-example">
            • Wrap important points in <div class="callout-important">
            • Highlight key terms with <mark>
            • Generate Mermaid diagram code where relevant
            • Suggest where images would help (with descriptions)
            • Output clean HTML that TipTap can consume
          - Returns: structured HTML + diagram code + image prompts

    [2.2] API key handling:
          - Stored in .env.local (never committed to git)
          - Accessed via process.env in the API route
          - We support OpenAI, Gemini, or Claude — just need to know which

    [2.3] The System Prompt (this is the SECRET SAUCE):
          - I will write a 200+ line system prompt that tells the AI exactly
            how to format notes for maximum visual impact
          - It will understand educational content structure
          - It will know when to add diagrams, callouts, highlights
          - This prompt is the CORE of the product — I'll craft it carefully
